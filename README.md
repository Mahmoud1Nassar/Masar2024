# 🐱 Pet Adoption Platform – Masar2024

A **Pet Adoption Web Application** built as a capstone in a 9-month training program.  
The app lets users browse cats available for adoption, submit requests, and manage listings in a clean, responsive UI.

## 🌟 Features
- Browse & search cats available for adoption
- User sign-up / login (demo flow)
- Submit and track adoption requests
- Add / edit pet profiles with photos
- Filter by category/age/availability
- Simple admin view to manage listings

## 🧰 Tech Stack
- **Frontend:** React (Create React App)
- **Language:** JavaScript (ES6+)
- **UI:** HTML5, CSS3, responsive layout
- **State:** React hooks
- **Data:** local JSON / mock API (can be switched to real API later)
